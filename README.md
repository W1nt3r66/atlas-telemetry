# PastelRide — Car Mileage, Expense & Convoy App

## Quick Start in VS Code (Runs Immediately!)
1. Extract this ZIP folder and open the folder in **VS Code**.
2. Open the Terminal in VS Code (`Ctrl + ~` on Windows or `Cmd + ~` on Mac).
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open **http://localhost:3000** in your browser!

## Features Included
- **Zero-Setup Instant Mode:** Works out-of-the-box with sample data saved locally in your browser so you can test every page immediately.
- **Cloud Sync (Optional & Free):** Copy `.env.local.example` to `.env.local`, paste your free Supabase + Gemini keys, and run `supabase_schema.sql` in Supabase.
- **Tamluk Anti-Rust Wash Reminder:** Adjusts wash reminders (21–30 days) based on coastal humidity and seasons, plus 10,000 km / 365-day service alerts.
- **Offline Convoy Walkie-Talkie:** Tap the floating **Walkie** button at the bottom-right to pair over a local phone hotspot with zero mobile data.
